# Wheel Fusion - Ride Sharing App

## Overview
**Wheel Fusion** is a ride-sharing web and mobile application designed to connect travelers on the same route. The platform enables users to share rides, reducing travel costs and making commuting more efficient. This project was developed as part of the **Smart India Hackathon (SIH)** competition.

## Features
- **Real-time Location Tracking**: Uses **Leaflet.js** to display live maps and track ride routes.
- **Destination Selection**: Users can manually enter their destination or use live location.
- **Ride Scheduling**: Users can schedule pickups for future rides.
- **User Profiles**: Enables users to manage their ride history and account details.
- **Fuel Cost Estimator**: Integrated tool to calculate fuel expenses for the journey.
- **Partner with Riders**: Users can find and connect with ride partners.

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP, MySQL (for user authentication and ride data storage)
- **Map API**: Leaflet.js for displaying and managing maps
- **Libraries**: FontAwesome for UI icons

## How to Run
1. Clone the repository:
   ```bash

   ```
2. Navigate to the project folder and open `index.html` in a browser.
3. Ensure you have a local or remote server for backend functionality (if applicable).
4. Configure the database (`MySQL`) for user authentication and ride storage.
